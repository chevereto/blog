[Chevereto V4.5.8](https://releases.chevereto.com/4.X/4.5/4.5.8) introduces important security patches that address vulnerabilities affecting older versions of Chevereto, including versions dating back to 3.0.0. This announcement explains the scope of these findings, their potential impact, and what they mean for existing installations.

In April 2025, I announced our [commitment to security vulnerability disclosure](https://chevereto.com/community/threads/introducing-self-discovered-vulnerability-disclosure-procedure.15973/). As part of that effort, Chevereto V4.5.8 underwent the largest security review in the project's history. I reviewed the entire codebase, with additional contributions from several independent security researchers. This work yielded 19 security fixes (8 moderate, 7 high, 4 critical).

## How are you affected?

The impact of these vulnerabilities depends on how you run and use Chevereto.

If you operate a multi-tenant installation or a public image-hosting service where users can upload and share files, your exposure will be higher. Depending on the vulnerability, an attacker could access sensitive user-generated content, or cause a denial of service on your website.

If you run a private, single-user installation for your own use, your exposure is much lower, and several attack scenarios may not apply to you at all.

The details and PoC of these vulnerabilities has been disclosed on 2026-11-10 following the two-week embargo period.

### Critical (4)

- `>= 4.0.0, < 4.5.8`
  - [Local file inclusion through the root_route setting](https://github.com/chevereto/chevereto/security/advisories/GHSA-5g43-84gf-625j)
- `>= 4.0.3, < 4.5.8`
  - [SQL injection via unvalidated client-IP header](https://github.com/chevereto/chevereto/security/advisories/GHSA-hp5x-4496-6jgf)
- `>= 3.0.0, < 4.5.8` (2)
  - [Profile settings mass assignment leads to arbitrary file delete and stored XSS](https://github.com/chevereto/chevereto/security/advisories/GHSA-557g-fhfm-c7pw)
  - [Arbitrary file move/delete through a forged upload source array](https://github.com/chevereto/chevereto/security/advisories/GHSA-26xc-wj28-v7hw)

### High (7)

- `>= 3.0.0, < 4.5.8` (2)
  - [Path traversal leads to arbitrary file delete through the watermark_image setting](https://github.com/chevereto/chevereto/security/advisories/GHSA-jm8p-7rq2-hfp9)
  - [Private album contents leaking on /json endpoint](https://github.com/chevereto/chevereto/security/advisories/GHSA-xmfh-627c-cfq8)
- `>= 3.7.0, < 4.5.8`
  - [Stored XSS through the image title in the Markdown embed codes](https://github.com/chevereto/chevereto/security/advisories/GHSA-wc2h-7xxm-hw4x)
- `>= 3.12.0, < 4.5.8`
  - [A manager can make any user an admin](https://github.com/chevereto/chevereto/security/advisories/GHSA-f38w-xxmx-32jh)
- `>= 4.0.0, < 4.5.8`
  - [2FA bypass](https://github.com/chevereto/chevereto/security/advisories/GHSA-mp4x-h8rg-vwx2)
- `>= 4.0.11, < 4.5.8`
  - [Authenticated visitor can trigger self-upgrade process](https://github.com/chevereto/chevereto/security/advisories/GHSA-m484-5vg9-v8rf)
- `>= 4.3.0, < 4.5.8`
  - [Server-Side Request Forgery in URL-based Image Upload](https://github.com/chevereto/chevereto/security/advisories/GHSA-ggg2-79hg-mwrp)

### Moderate (8)

- `>= 3.0.0, < 4.5.8` (4)
  - [Path traversal in the theme setting](https://github.com/chevereto/chevereto/security/advisories/GHSA-pgc9-8847-7qh9)
  - [Profile settings mass assignment leads to bypass username filters, claim unregistered email and stored XSS](https://github.com/chevereto/chevereto/security/advisories/GHSA-5f65-qgww-88c6)
  - [Image editing doesn't check album existence neither user ownership](https://github.com/chevereto/chevereto/security/advisories/GHSA-g6xr-mvc6-f96m)
  - [Album editing doesn't check album existence neither user ownership](https://github.com/chevereto/chevereto/security/advisories/GHSA-rxm7-p625-xcw3)
- `>= 3.5.14, < 4.5.8`
  - [Any logged-in user can delete IP bans](https://github.com/chevereto/chevereto/security/advisories/GHSA-9927-9xg3-f247)
- `>= 3.7.0, < 4.5.8`
  - [Users can discover private content via unrestricted "like" functionality](https://github.com/chevereto/chevereto/security/advisories/GHSA-93gh-w88q-6656)
- `>= 3.8.4, < 4.5.8`
  - [Private profile setting leaking liked/follow on /json endpoint](https://github.com/chevereto/chevereto/security/advisories/GHSA-rmhr-j77c-f7vq)
- `>= 3.12.0, < 4.5.8`
  - [Managers can remove 2FA, API keys and profile pictures of admins and other managers](https://github.com/chevereto/chevereto/security/advisories/GHSA-8j68-h3c6-268c)

## Chevereto V3 & Chevereto-Free

Many websites are using Chevereto V3 despite being EOL since 2022-11: 35% of our user base according to [W3Techs](https://w3techs.com/technologies/details/cm-chevereto). The same goes for [Chevereto-Free](https://github.com/rodber/chevereto-free) (unknown usage) which was superseded by [chevereto/chevereto](https://github.com/chevereto/chevereto).

The best way to get your systems secured is to update to the V4 branch. You can go with any edition as both the Open Source edition and paid editions bundle the same security patches.

## Helping everybody upgrade

Our priority is to help all affected installations move to a secure, patched version. To support that effort, the Chevereto Pro subscription [has been recently upgraded](https://chevereto.com/community/threads/chevereto-pro-now-includes-pro-support-and-on-site-support.16440/) to provide all-service support, which includes on-site system updates. If you have any issues updating, we will perform the update on your behalf at no extra charge so you can rest assured your website will work as expected.

We have prepared discount coupons of up to 80% off for all former customers within 5 years of their last activity. The discount takes previous purchases into account, helping us make the upgrade more accessible to those who have supported Chevereto over the years. If you are a former customer, visit [chevereto.com/panel/coupons](https://chevereto.com/panel/coupons) to redeem your long-time customer discount.

## Chevereto Cloud

Chevereto Cloud users **aren't affected** as the patches have already been implemented. There's no action required for Chevereto Cloud customers.

Feel free to [contact us](https://cloud.chevereto.com/contact) if you want to migrate your self-hosted website to the cloud.
